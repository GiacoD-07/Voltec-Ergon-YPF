US-01: [FW-01] Captura de Variables Eléctricas mediante PZEM-004T
Narrativa de Usuario

Como firmware del microcontrolador ESP32

Quiero leer las magnitudes eléctricas (voltaje, corriente, potencia activa, energía y frecuencia) desde el sensor PZEM-004T vía UART Modbus

Para disponer de telemetría de consumo eléctrico precisa en tiempo real

Descripción / Contexto

Implementación del driver de comunicación serie RX/TX en el entorno PlatformIO (platformio.ini) utilizando la librería PZEM004Tv30.

Criterios de Aceptación
Escenario: Lectura correcta de magnitudes eléctricas

Dado que el sensor PZEM-004T está conectado al puerto serie secundario del ESP32 y energizado con 220V AC

Cuando el ciclo principal loop() ejecuta la función de muestreo

Entonces el sistema obtiene los valores de Voltaje (V), Corriente (A), Potencia (W) y Energía (kWh)

Y almacena los datos en la estructura en memoria local

Escenario: Fallo de lectura por desconexión o ruido en la línea UART

Dado que la línea de datos RX/TX del sensor sufre una desconexión física

Cuando la función de muestreo intenta realizar la petición de datos

Entonces el sistema debe mostrar el mensaje de error: "Error de lectura en sensor PZEM-004T: Modbus Timeout"

Comentarios Adicionales
Notas sobre limitaciones técnicas: El refresco de lectura debe realizarse a intervalos no inferiores a 1 segundo.

Dependencias con otras historias de usuario: Ninguna.

Referencias a documentación externa: Archivo platformio.ini y firmware/main.cpp.
